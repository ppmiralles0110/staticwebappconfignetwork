You're on the allow list

This page is served by Azure Static Web Apps. You can see it because your public IP address matches an entry in allowedIpRanges.

Every request from an IP outside that list is denied before it ever reaches this file.

The rule in force

{
  "networking": {
    "allowedIpRanges": [
      "203.0.113.42/32",
      "198.51.100.0/24"
    ]
  }
}

Try it

  1. Load this page from an allowed network — you get this page.
  2. Switch to mobile data or a VPN, then reload — access is denied.
  3. Add that second IP to allowedIpRanges, redeploy, reload — you're back in.

Requires the Static Web Apps Standard plan. IP blocks use CIDR notation; /32 allows exactly one address.
